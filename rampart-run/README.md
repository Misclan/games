# Rampart Run

A crowd-shooter / gate-runner for the browser. Lead a warband down a bridge or along a dock. Run through banners to multiply your soldiers, shoot perk barrels open, cut down zombie hordes and acid spit, and kill the boss before it reaches you.

**Play:** open `index.html` (no build, no dependencies), or run `node tools/bundle.js` for a single self-contained file.

## How it plays

- Drag left and right (or A/D, arrow keys). The squad runs and shoots by itself, faster the bigger it is.
- **Banners** are applied once as you run through: `×3` multiplies the soldiers you have, red `÷` and `−` banners shrink them.
- **Grey crowds** add recruits. They are separate from the banners.
- **Barrels** show how many bullets they need and count down as you shoot. Break one for a random perk: Reinforce, Rapid fire, Shield, Spread, Piercing or Heavy shot. Better perks need more bullets.
- **Crates** (about 200-300 bullets) unlock an auto turret or a drone that fights beside you and can be destroyed.
- **Zombie waves** swarm toward you in random sizes. Survivors that reach you kill that many soldiers. From level 3 some spit acid; shoot the globs down or sidestep them.
- **Spikes** cost a quarter of the squad unless you take the gap.
- **The boss** ends every level. It only hurts you by reaching you: a critical melee strike kills nearly half the squad plus a flat amount, so a 150 squad lasts about three strikes. It also throws items that fit the stage (cars and railings on the bridge, containers and oil drums at the port). Steer away from the red shadow.
- Every fifth level is a stream: a dense line of zombies with the boss in the middle.

## Layout

| Path | What |
|---|---|
| `src/sim.js` | Rules engine. Pure and deterministic, runs in the browser and in Node. Level generator and solver live here. |
| `src/game.js` | Canvas drawing, input, screens, save (`localStorage`). |
| `src/cal.js` | Generated by `tools/calibrate.js`: difficulty and layout variant per level. |
| `test/smoke.js` | `node test/smoke.js`. Rule checks plus a solver pass over levels 1-60. |
| `tools/calibrate.js` | Finds a difficulty for each level that a perfect run can beat. |
| `tools/bundle.js` | Writes a single-file build. |
