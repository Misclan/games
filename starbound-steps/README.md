# Starbound Steps

A bright, original side-scrolling platform adventure. Run across floating paths, gather starlight, bounce on little trail bugs and reach the pennant.

## Play

Open `index.html` in a modern browser. It is a self-contained game with no installation, build step, libraries or network requests.

- **Move:** Left/Right arrows or A/D
- **Jump:** Space, Up arrow or W
- **Pause:** P or Escape
- **Touchscreens:** Use the on-screen direction and jump buttons
- **Sound:** Turn optional synthesized sound on with the Sound button

Progress and your best star count are stored locally in the browser.
